# Product Spec — DXT People & Operations

## Purpose

Replace fragmented internal HR/operations workflows currently spread across Notion, Excel, Wanted Space/Handysoft, Gmail, and spreadsheets.

## Primary users

- Employee
- Team Leader
- Division Head
- Expense Admin
- IT Admin
- Admin
- CEO

One person may hold multiple roles.

## UX principles

- Desktop-first, responsive.
- Clean B2B SaaS visual language.
- Use DXT brand color for primary actions and selected states.
- Avoid dashboard vanity metrics.
- Frequent employee actions should be 1–2 clicks.
- Tables for dense admin views.
- Friendly warnings, not punitive copy.
- Progressive disclosure for sensitive/policy details.
- Hide unauthorized navigation.
- Avoid complex electronic approval patterns where simple confirmation is enough.
