# Figma assets

Unmodified SVG exports supplied by `get_design_context` for the approved DXT HR file:
https://www.figma.com/design/BL670ZpeySoSAhEZLgK62e/DXT-HR_AI?node-id=15-7

Frames 01 (`15:7`) and 13 (`29:22`) use the same icon set. The original SVG dimensions are preserved: navigation 16×16, breadcrumb 12×12, sidebar avatar 32×32, header avatar 28×28. `AppShell` and the route registry map these assets to their corresponding design slots. Avatar assets are neutral placeholders until real profile images are introduced in Phase 2. No temporary Figma asset URLs are used at runtime.
